# VerifAI - AI Image Detection System

A modern web application for detecting AI-generated and manipulated images using MT-YOLOv6 and credibility scoring.

## Features

- **Real-time Image Analysis**: Upload and analyze images instantly
- **MT-YOLOv6 Integration**: Advanced object detection for AI patterns
- **Credibility Scoring**: Quantitative reliability assessment
- **Visual Annotations**: Highlighted regions showing detected anomalies
- **Responsive Design**: Works seamlessly across all devices
- **Modern UI**: Beautiful glass-morphism design with smooth animations

## File Structure

```
VerifAI/
├── index.html          # Main HTML file
├── styles.css          # Custom CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## Getting Started

1. Clone or download the project files
2. Open `index.html` in a web browser
3. Upload an image to start detection

## Usage

1. **Upload Image**: Click the upload area or drag & drop an image
2. **Analyze**: Click "Analyze Image" to process with MT-YOLOv6
3. **View Results**: Check detection results, confidence scores, and credibility ratings
4. **Visual Indicators**: See highlighted regions with detected AI patterns
